# Club Management System

A modern web application for managing and exploring college clubs, courses, learning activities, quizzes, and student progress.

## Features

* Club and course browsing
* Course details and learning pages
* Student dashboard
* User login interface
* Interactive quizzes
* Learning progress tracking
* Certificate page
* Responsive UI
* Next.js-based frontend

## Tech Stack

* Next.js 14
* React
* TypeScript
* Tailwind CSS
* Node.js
* Vitest

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Dhanu2408/club-management-system.git
cd club-management-system
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run the development server

```bash
npm run dev
```

Open `http://localhost:3000` in your browser.

### 4. Build for production

```bash
npm run build
```

### 5. Start the production server

```bash
npm start
```
